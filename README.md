# CoursePulse — трекер учебной группы

Локальный проект на Python, pandas и Excel для куратора курса: посещаемость, домашние задания, причины пропусков, сводный отчёт и список слушателей для связи. Есть настольное окно на Tkinter и командная строка.

## Быстрый старт

1. Распакуйте архив.
2. Для Windows установите Python 3.11/3.12 с Tkinter и Python Launcher.
3. Запустите `start_windows.bat`.
4. Для готового примера без установки откройте `reports/example/report.html` или `reports/example/course_report.xlsx`.

На вкладке «Внести отметку» можно изменить посещаемость и статус домашней работы. На вкладке «Сводка» — задать дату среза, обновить расчёт и сформировать Excel/HTML. Для воспроизведения демонстрации используйте дату `2026-10-29T18:00:00+03:00`.

Демо содержит шесть вымышленных слушателей, пять занятий и три задания. Контакты используют домен example.com. Реальных персональных данных в комплекте нет.

## Что делает проект

- Проверяет схему CSV, уникальность ключей, статусы, связи, периоды обучения и часовые пояса.
- Считает только прошедшие занятия, подходящие группе и периоду обучения слушателя.
- Различает пропуск, уважительную причину и неизвестную отметку.
- Показывает принятые, отправленные, просроченные и возвращённые на доработку работы.
- Формирует сводку и отдельную очередь связи с причиной и рекомендуемым действием.
- Сохраняет черновики сообщений; отправка сообщений не выполняется.
- Экспортирует Excel с фильтрами, закреплением строк, формулами долей и выделением просрочек; CSV, JSON и HTML.
- Позволяет обновлять отметки через GUI и CLI, сохраняет CSV атомарной заменой.

## Установка вручную

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m coursepulse.cli gui --data data/demo
```

Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -r requirements.txt`. Для GUI нужен Tkinter; CLI работает без графической среды.

## Команды

```bash
python -m coursepulse.cli report --data data/demo --as-of 2026-10-29T18:00:00+03:00 --output reports/current
python -m coursepulse.cli attendance --data data/demo --student S002 --session L02 --status absent --reason "Рабочая смена"
python -m coursepulse.cli submission --data data/demo --student S003 --assignment HW02 --status accepted --submitted-at 2026-10-29T17:00:00+03:00 --comment "Доработка принята"
python -m coursepulse.cli init --data data/work
python -m unittest discover -s tests -v
```

`init` создаёт пустые CSV и не перезаписывает существующие файлы. Для новой демонстрации используйте `init --data data/new-demo --demo`.

## Работа со своими данными

Создайте `data/work`, заполните слушателей, занятия и задания, затем вносите отметки. Идентификаторы не должны меняться после появления связанных записей. Таблицы входа редактируются в CSV или через команды; изменение Excel-отчёта не меняет исходные данные. Отчёт — снимок расчёта, обновляемый повторным запуском. Не храните реальные контакты и причины пропусков в публичном GitHub-репозитории.

## Границы

Проект рассчитан на одного куратора и локальные файлы. Нет многопользовательской блокировки, интеграции с LMS и автоматической отправки напоминаний. Для долгой командной работы нужны база данных, права доступа и журнал истории изменений. Статусы работ хранятся в последнем состоянии: прошлый срез фильтрует даты событий, но не восстанавливает историю изменения оценок. Метрики относятся к учебной активности и не доказывают освоение материала.
