# Проверка проекта

29 октября 2026 года. Python 3.12, pandas 2.2.3.

- 21 автоматический тест расчёта, валидации, обновления данных и переносимого Excel-экспорта прошёл.
- Проверены: пропуски и неизвестные отметки, уважительные исключения, опоздания, дедлайн в точности на границе, будущие занятия/сдачи, периоды обучения, отсутствие повторов и сохранение файла при некорректном обновлении.
- Проверены очередь связи, черновики, HTML-экранирование и защита CSV от интерпретации пользовательского текста как формулы.
- CLI report выполнен на демонстрационных данных без графического окружения.
- Результат на 2026-10-29 18:00 +03:00: шесть слушателей, 24 ожидаемых посещения, 20 фактов участия, два пропуска, одна уважительная причина и одна неизвестная отметка. В очередь связи попало пять человек.
- Демонстрационный Excel создан и визуально просмотрен на всех четырёх листах. Проверены доли, отсутствие ошибок формул, пересчёт после изменения входных счётчиков и восстановление исходных значений.
- Готовый Excel является снимком того же JSON/CSV-расчёта. Переносимый Python-экспорт дополнительно выполнен во временной папке в интеграционном тесте: проверены листы, русские заголовки, счётчики, формулы, фильтр, даты и флаг пересчёта при открытии. Его формулы пересчитываются Excel при открытии.
- Python-код скомпилирован, конфигурация CI разобрана как YAML.
- Настольное окно Tkinter, Windows bat и работа в самом Microsoft Excel здесь не запускались. Tkinter доступен для импорта, графический дисплей отсутствует.

Проверка после установки: `python -m unittest discover -s tests -v`. Для GUI запустите start_windows.bat; для повторения примера — build_example.bat.
