# Формат входных данных

CSV в UTF-8, разделитель — запятая. Если текст содержит запятую, используйте корректное CSV-экранирование кавычками. Порядок столбцов соответствует шаблонам. Временные поля — ISO 8601 с часовым поясом: `2026-10-29T18:00:00+03:00`.

| Файл | Поля |
|---|---|
| students.csv | student_id, name, group, contact, enrolled_at, ended_at |
| sessions.csv | session_id, group, title, start_at |
| attendance.csv | student_id, session_id, status, reason |
| assignments.csv | assignment_id, group, title, released_at, due_at |
| submissions.csv | student_id, assignment_id, submitted_at, status, comment |

`ended_at` пусто для продолжающего обучение. Момент выхода исключается из активного периода. contact может быть пустым: тогда способ связи уточняется отдельно.

Статусы посещения:

- present — присутствовала;
- late — опоздала, но участвовала;
- absent — отсутствовала;
- excused — уважительная причина.

Отсутствие строки посещения означает unknown, а не absent. Причина может быть пока пустой: отчёт отдельно покажет, что её нужно уточнить. В учебном журнале достаточно краткой общей причины без чувствительных подробностей.

Статусы домашних работ:

- submitted — сдано, ожидает проверки;
- accepted — принято преподавателем;
- revision — требуется доработка.

Отсутствие строки до дедлайна означает not_started, после дедлайна — overdue. submitted_at — время сдачи последнего сохранённого варианта; статус указывается текущий. Для пары студент/задание хранится одна запись.

Правила ключей:

- student_id, session_id, assignment_id уникальны в своих справочниках;
- посещаемость уникальна по студенту и занятию;
- работа уникальна по студенту и заданию;
- группы связанных записей должны совпадать;
- слушатель должен быть зачислен к моменту занятия или выдачи задания.

Таблицы можно читать/редактировать в Excel, но сохранять именно в CSV UTF-8. Папку с исходными CSV резервируйте перед массовыми изменениями. Во время записи другим процессом файлы редактировать не следует.
